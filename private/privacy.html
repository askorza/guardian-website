EXPERIMENTAL PRIVATE BETA

Privacy is a product decision.

Guardian Private Vault is a prototype, not a security-audited or regulated-data service. Please do not store extremely sensitive information here.

What is stored?

Your memories are Markdown records encrypted in your browser with AES-256-GCM before being written to local OPFS storage (or encrypted IndexedDB on unsupported browsers). File references store selected metadata and, when practical, a cryptographic fingerprint; original files aren't uploaded or duplicated. Your passphrase is never stored or transmitted. A salt and an encrypted verification record are stored so the vault can be unlocked with the correct passphrase.

Does Guardian send information to a server?

This private vault doesn't send notes, documents, passwords, telemetry or AI requests to a backend. The static website must still be delivered over HTTPS by the hosting provider; hosting infrastructure can process connection metadata such as IP addresses and requests as part of normal operations. We don't control the host's infrastructure logs.

How does encryption work?

The browser derives a non-extractable AES-256-GCM key with PBKDF2-SHA-256 (400,000 iterations) and a unique random salt. A fresh random IV is used for each record, with authenticated associated data binding the ID. Only the encrypted record is persisted. Your passphrase is needed after a refresh or lock. Strong passphrases matter; this prototype has not undergone independent security review.

What can go wrong?

Browser storage may be erased or evicted; your data can be lost if you forget the passphrase. Client-side encryption does not protect an unlocked vault against malware, a malicious browser extension or compromised site scripts. Browser caches, memory snapshots, backups and unencrypted exports may contain remnants of data. Deleting a local record is not a guarantee of forensic secure erasure on flash storage. Previously exported backups are unaffected.

Export, backup, and forgetting

By default, a vault backup is still encrypted and portable across devices. Import requires an empty vault and the original passphrase. Readable .md exports require an explicit confirmation. You can forget specific notes or a category at any time. Cloud sync and AI processing aren't part of this beta.

Hosting, account, and support

The private vault is intended for a dedicated free HTTPS Cloudflare Pages origin distinct from the public GitHub Pages marketing site. We do not provide accounts, billing, or recovery in this beta. No personal information is requested to use it.
